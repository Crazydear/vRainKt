# vRainKt —— 兀雨中文古籍刻本风格直排电子书阅读及制作工具

[![Version](https://img.shields.io/badge/version-v1.5-blue.svg)](https://github.com/shanleiguang/vRain)
[![Language](https://img.shields.io/badge/language-Kotlin-brightgreen.svg)](https://kotlinlang.org/docs/multiplatform/get-started.html)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Android%20%7C%20Desktop-lightgrey.svg)]()

vRainKt是基于[vRain（兀雨）](https://github.com/shanleiguang/vRain)的Kotlin Multiplatform (KMP)项目，可将中文文本生成为古籍刻本风格的直排（竖排）电子书。

## 本项目已实现的功能： ##

1. 通用画布绘制。
2. 可视化画布设计，并导出`.cfg`配置文件。
3. 画布做旧。
4. 竹简画布。
5. 文字排版。
6. 以下格式已支持
   - 抬头/顶格/进一字 (T)
   - 书名号左侧波浪线 《》
   - 圆角方框 〔〕
   - 圆形框 〈〉
   - 右侧圈注 ｛｝
   - 右侧点注 ＜＞
   - 右侧线注 ［］
7. 文字排版可视化加标签。
